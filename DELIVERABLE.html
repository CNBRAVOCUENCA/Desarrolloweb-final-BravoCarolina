Proyecto: Sitio estático institucional en HTML + SASS — 5 páginas

1. Introducción

Nombre: Bravo Studio

Tipo: Institucional (ficticio). Objetivo: Mostrar servicios, portfolio y contacto con identidad visual en SASS.

2. Estructura HTML

Archivos incluidos: index.html, about.html, services.html, portfolio.html, contact.html. Todas las páginas usan HTML5 semántico y una navegación consistente.

<nav class="navbar"> ... </nav>

3. Estilos CSS / SASS

Carpeta: assets/scss/ con partials: _variables.scss, _mixins.scss, _base.scss, _layout.scss, _components.scss y main.scss. CSS compilado: assets/css/style.css.

$primary: #2a6f9e;

4. Responsive y Estilos Avanzados

Se aplican breakpoints via mixin respond-to, Bootstrap grid para layout, y AOS para animaciones en scroll. Pruebas en Desktop/Tablet/Mobile completadas (capturas recomendadas).

5. Repositorio

URL del repo: https://github.com/CNBRAVOCUENCA/Desarrolloweb-final-BravoCarolina

Ramas: main y gh-pages. Historial con commits claros incluidos.

6. Demo pública

Se cumplió con los requisitos: 5 páginas, SASS modular, uso de SEO básico, responsive y despliegue en servidor. La integración con el remoto requirió resolver historial previo; una vez resuelto, se publicó en gh-pages.
